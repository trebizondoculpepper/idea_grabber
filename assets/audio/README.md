# Idea Grabber sound source library

Open audition.html in a browser to search and listen to the downloaded clips. inventory.json records paths, durations, sizes and SHA-256 checksums. SOURCE.json in each pack records origins; licence files are kept alongside audio.

The packs are source material, not final game cues. See ../../docs/sound-effects.md for the cue plan. All sources are CC0 except tcarisland Talking Synthesizer (CC BY 4.0). Credit it when used; retain source links and state edits. The marble recording is the public HQ preview. Signature Sounds was not downloaded because it uses checkout delivery.

These files are outside public/ and are not bundled into the game. After auditioning, copy only chosen, edited cues into public/audio/ with their credits.
