# Idea Grabber — soundtrack generation prompt

You are creating the soundtrack for Idea Grabber, a goofy, hyper-coloured browser arcade game. A cartoon lightbulb called Bulbee and an enthusiastic coin called Coinie stand beside a claw machine that grabs colourful balls representing game ingredients. The visual style mixes flat paper characters, chunky low-poly geometry and glitchy PS1 graphics. The soundtrack should make this ridiculous arcade feel alive.

## Deliverable

Produce a bank of **40 separate instrumental music snippets**, each **20–40 seconds**, aiming for about 30 seconds. The game plays them in shuffled order with short crossfades, so the random sequence of snippets becomes a medley.

**Each snippet is a goofy chiptune pastiche of exactly one notable video game theme.** Write an original melody that a player would instantly associate with that theme: match its groove, tempo feel, harmonic language, instrumentation, signature rhythms and melodic contour, so it sounds like a long-lost sibling of the original. Do not transcribe the original melody note for note. Stay with a single source theme for the whole file.

The source themes are drawn from across 1980s and 1990s arcade, console and home-computer games. Give each track a clear musical identity. The bank should be varied but sound like one eccentric house band.

## Musical direction

- Joyful, cheeky, bouncy and slightly ridiculous. Think tiny arcade band with too much sugar.
- Square-wave leads, triangle-wave bass, pulse arpeggios, crunchy noise drums, FM keyboard/brass colours and occasional deliberately cheap synth flourishes.
- Melodic humour: octave jumps, slide whistles, brief wrong-note feints that resolve, tiny breakdowns, exaggerated fills and unexpected but musical transitions.
- Keep each pastiche melody audible and memorable beneath the playful arrangement.
- Mix arcade, NES, Game Boy, Mega Drive, SNES, Amiga and N64 flavours according to each source theme. Bright chip timbres should stay comfortable over extended listening.
- Mostly energetic tempos around 110–165 BPM, with a few relaxed tracks around 85–110 BPM.
- Instrumental throughout. Leave room for the characters' future voices and machine sound effects.

## Arrangement and transition requirements

- Start with music within 0.1 seconds. No long intros.
- Make each file a complete little musical vignette, not a random cut from a longer song.
- End on a clean musical boundary with a short tidy release. No long silence or sprawling reverb tail.
- Keep the last 0.75 seconds suitable for a gentle crossfade into an unrelated track. The game's player handles the crossfade.
- Loudness: **−16 LUFS integrated**, true peak **≤ −1 dBTP**, consistent across the bank. No clipping and no tiring high-frequency noise.
- Light stereo width with a solid centre and good mono compatibility.
- The retro character comes from instruments and arrangement. Export clean, full-quality audio.
